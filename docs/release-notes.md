## Download

**[⬇ IpaToolGui.exe](https://github.com/DuyTaDinh/ipatool-gui/releases/latest/download/IpaToolGui.exe)**: runs directly on Windows 10/11, nothing to install.

- On first launch the app downloads the latest ipatool from [majd/ipatool](https://github.com/majd/ipatool/releases).
- If SmartScreen warns you: **More info → Run anyway** (the exe isn't code-signed yet).
- Verify the file: compare its SHA-256 with `IpaToolGui.exe.sha256`, or run
  `gh attestation verify IpaToolGui.exe --repo DuyTaDinh/ipatool-gui`.
