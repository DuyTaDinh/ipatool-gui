# Changelog

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-16

### Added
- Downloads, verifies (SHA-256) and auto-updates the latest ipatool release from GitHub (Windows amd64/arm64).
- Apple ID sign-in with two-factor authentication.
- Search by app name, bundle ID or App ID; platform filter for iPhone/iPad, Mac, Apple TV, Apple Watch and Vision Pro.
- App details: icon, screenshots, description, what's new, rating, size and an Open in the App Store button.
- Older versions: list version IDs, resolve version numbers and release dates, download a specific version.
- Download queue with progress, cancel, resume and "show in folder".
- Owned apps list with paging.
- UI in English, Tiếng Việt, 简体中文, 한국어 and Türkçe; follows the Windows language by default and switches live.
- Dark, Light and System themes (System by default), including a matching window title bar.
- Settings: download folder, automatic licenses for free apps, App Store country, keychain passphrase (stored with DPAPI), session reset.
- Log of ipatool commands with passwords, 2FA codes and passphrases hidden.
- Notification when a new IPA Tool GUI release is published on GitHub.
