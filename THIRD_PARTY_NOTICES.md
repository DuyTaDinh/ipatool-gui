## ipatool

IPA Tool GUI is a graphical front end for **ipatool** by Majd Alfhaily.
ipatool is **not bundled** in this repository or in `IpaToolGui.exe`: on first run the app downloads the
official Windows build from <https://github.com/majd/ipatool/releases>, verifies its SHA-256 checksum and
runs it as a separate process.
